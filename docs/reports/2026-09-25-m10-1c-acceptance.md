# M10 第 1c 片：切换键与审阅屏自动拿到光标的有人值守验收（2026-09-25）

## 结论

**第 1c 片在产品提交 `6e9a73ad` 上，以 DeepSeek 和用户在场审批的方式通过验收：chat 入口在编辑模式、act 入口在 agent 模式各一次，四个阶段各 11 项自动检查全过；四次审阅屏都是自己出现、出现时光标已在它上面，不需要任何切换键。四份最终答复经 leader 审阅，没有与观察相矛盾的"已应用／已保存／已撤销"陈述。** 两种模式各只有一次通过，不是成功率。切换键 `C-c C-w` 不在应用／撤销流程里，它在真实终端 Emacs 里的检查见 `.scratch/m10-1c/real-window/`（真按键：切出、切回、没发的字还在）。

## 留档的瑕疵（不涉及已应用／已保存／已撤销的状态）

1. chat 应用答复："修改前 `work.el` 里 `key-binding` 为 `nil`（`with-eval-after-load` 大概还没执行）"——那个 `nil` 是在聊天 buffer 里测出来的，同一次调用的 `lookup-key` 为 `ignore`，说明它已执行。
2. act 应用答复：把 `lookup-key` 返回的 `2` 读成"`C-c t` 是前缀"；数字的意思是那个键表里没有这个绑定（参考页的错误说法，已登记 `2026-09-25-reference-page-misstates-lookup-key-number`）。
