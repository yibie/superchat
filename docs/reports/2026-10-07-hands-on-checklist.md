# 实机上手测试：步骤与问题记录

对应提交：`15cfc08b`（2026-10-07）。前四步的证据全部来自沙箱 Emacs 和替身用户，这份清单要补的是"真人在键盘前"。

用法：在你日常的 Emacs 里照着做，每做完一步，在该步的"记录"里填写。不必一次做完，也不必按顺序；第 1 步的准备要先做。

## 怎么填

每一步的"记录"有四栏：

- **结果**：填 `符合` / `不符合` / `没做` / `说不清`。
- **实际看到的**：和"应该看到"不一样的地方，照你看到的写，不用分析原因。
- **打扰程度**：填 `没打扰` / `有点烦` / `打断了我`。行为对但让你不舒服，也要写在这里。
- **证据**：能留就留。最有用的是：出问题的时间（几点几分）、对话的名字、`*Messages*` 里相关的几行。

不在清单里、但用的时候碰到的问题，写到最后的"清单外的问题"。

## 0. 准备

1. 确认 Emacs 加载的是这个仓库的当前代码：`M-x locate-library RET superchat RET` 指向本仓库；改过代码后重启一次 Emacs。
2. 准备一个可以随便改的练习项目，不要直接用重要的仓库：

   ```sh
   mkdir -p ~/superchat-practice && cd ~/superchat-practice && git init
   printf '* 检查记录\n' > log.org
   printf '* 草稿\n第一段。\n' > draft.org
   printf '* 购物清单\n- 牛奶 2 盒\n- 鸡蛋 6 个\n' > list.org
   printf '* 通知\n大家好。\n我们定在2026年10月9日下午三点开会，记得带电脑哦。\n' > notice.org
   printf '回答用中文。\n日期写成 2026-10-09 这种格式。\n每次回答先写一行以“思路：”开头的话。\n' > AGENTS.md
   git add -A && git commit -m init
   ```

3. 再准备第二个项目，用来检查两个 Workspace 互不串门：

   ```sh
   mkdir -p ~/superchat-practice-b && cd ~/superchat-practice-b && git init
   printf '* B\n' > b.org && git add -A && git commit -m init
   ```

4. **用单独的测试实例时，先验证数据目录真的换了。**（2026-10-12 加的。那天的一次实测本想用独立数据，结果写进了日常的数据库：测试实例在命令行里设了 `superchat-data-directory`，但配置里设置它的那个模块是启动后空闲时才加载的，后加载的把先设的盖掉了。）

   - 不要让两个 Emacs 同时用同一个 superchat 数据库。
   - 测试实例启动后，等配置全部加载完（空闲几秒），在**第一次** `M-x superchat` 之前执行：`M-: (setq superchat-data-directory (expand-file-name "~/.cache/superchat-handson-data/"))`。superchat 是按需加载的，要赶在它加载之前。
   - 验证一：`C-h v superchat-data-directory` 显示的是测试目录。
   - 验证二：打开对话后，"最近的对话"列表是空的，没有你平时的对话。
   - 验证三：发出第一条消息后，测试目录里出现了 `superchat.db`（`ls ~/.cache/superchat-handson-data/`）。
   - 三条有一条不对就停下，不要继续测。

常用按键，测试时会用到：

| 做什么 | 怎么做 |
|---|---|
| 打开对话 | 在文件 buffer 里 `M-x superchat` |
| 发送 | 对话里 `C-c C-c` |
| 停止正在跑的执行 | 对话里 `C-c C-k` |
| 侧栏和整页之间切换 | 对话里 `C-c C-w` |
| 审阅屏 | `s` 保存这个 buffer，`n` 不保存看下一个，`q` 离开 |
| 手动打开审阅屏 | `M-x superchat-changes`，或对话里输入 `/changes` |
| 工作记录列表 | `M-x superchat-work-list`，`RET` 打开一条，`c` 标为完成 |
| 改写选区 | 选中文字后 `M-x superchat-rewrite-region`；`C-c C-a` 接受，`C-c C-k` 拒绝 |
