# Domain docs

This is a single-context repository.

Before investigating or designing:

- Read the root `CONTEXT.md`.
- Read relevant decisions in `docs/adr/`.
- Use the glossary's domain terms consistently.
- Explicitly identify any proposed conflict with an existing ADR.

If a document is absent, continue without requiring its creation.
Code and tests establish current behavior; distinguish that behavior from
proposals and historical design records.

This configuration introduces no separate approval or publication ceremony.
