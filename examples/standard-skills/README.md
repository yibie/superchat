# 目录式 Skills 材料示例

这些示例保留 `<name>/SKILL.md` 和可选 `references/` 的组织方式，供阅读与改编；它们不是 Superchat 自动发现或执行的插件包。

## 在 Superchat 中使用

先阅读所选 SKILL.md，把需要的提示词保存为 `superchat-skills-directory/<name>.md`，按照[本地 Skills 教程](../../docs/SKILLS_QUICKSTART.md)整理 frontmatter。用 `>name` 显式调用；不要覆盖同名文件，也不要假定引用目录、脚本或全部第三方元数据会自动被加载。

当前 checkout 不提供 `superchat-skills-standard.el` 或同名前缀的导入、导出和初始化命令。目录中的其他示例只描述各自的提示词材料，不证明跨工具兼容性或 Superchat 的运行行为。
