# NOTES

One line per unclear point or conflict, newest last.

- `utils-retry`/`utils-provider-retry` (transform/retry port): the source's callbacks may be async; the Lisp ones are plain functions and their results are ignored. `FINISH` gets `(:ok V)` or `(:error E)`.
- `utils-provider-retry`: an error is retried only when it is a plist with `:message`, `:status` and `:headers` all present (even nil); the caller of the OpenAI-completions port must turn HTTP status >= 400 and the HTTP seam's `(:error KIND ...)` into such a plist.
- `utils-error-body`: the source reads SDK error objects; the Lisp form is a plist (keys in the file header) or a Lisp error condition. The openai-completions port must build the plist from the HTTP response (`:status`, `:error` as a hash table, `:body` as a string).
- `utils-retry` first defined its own `superchat-bridge-abort-signal`; replaced by `superchat-bridge-utils-abort.el`, whose `superchat-bridge-abort-signal-aborted-p` rejects nil (so retry code uses its own `superchat-bridge--signal-aborted-p` for a nil signal).
- `utils-sanitize-unicode` adds `superchat-bridge-string-trim-js` and `superchat-bridge-utf16-length`, which are not in the source; `transform-messages` and `error-body` need them.
- models/auth: `data/deepseek.json` holds `deepseek-flash` and `deepseek-v4-pro`; there is no `deepseek-v4-flash` in the 1.4.0 data.
- models: `src/api/lazy.ts` (`lazyStream`, `lazyApi`, `ProviderStreams`) has no owner; ported inside `superchat-bridge-models.el` under the final names, move to `superchat-bridge-api-lazy.el` when someone owns it. `ProviderStreams` also belongs in `superchat-bridge-types.el`.
- models: `src/utils/transcript.ts` is only half ported (`createInitialSystemMessage`, `normalizeContext`) in `superchat-bridge-utils-transcript.el`; whoever ports the rest extends that file.
- models: `src/utils/identity.ts` is not ported; `applyAuth`'s OpenCode session header and the `identity` option of `createModels` are left out, a request's `:identity` passes through untouched.
- representations chosen (not in PORTING.md §6): options are plists with keyword names of the source's fields; headers and env are alists; auth result and credential are plists; credential `:type` is the symbol `api_key`; JSON `null` in a thinking-level map is `:null`; model `compat` keys are kebab-case symbols (acronyms are words: `supportsOpenAIGrammarTools` -> `supports-open-ai-grammar-tools`), false is nil so test presence with `assq`.
- abort: `AbortController` and `AbortSignal` are one struct `superchat-bridge-abort-signal`; HTTP's `superchat-bridge-http-abort` takes a handle, so a streaming API must add a listener to the signal that calls it.
- event-stream: `superchat-bridge-event-stream--time` compares a message timestamp in milliseconds with `started-at` in seconds, so its "stamped before the stream" guard never fires; `lazy-stream` stamps setup errors in milliseconds as `Date.now()` does.
- headers: a header value of nil and `:null` both mean the source's `null` (remove); `superchat-bridge--merge-headers` keeps either as it is.
- openai-completions: `src/index.ts` exports no `stream`/`streamSimple`; `superchat-bridge.el` only requires and provides. The file-private copies of `transcript.ts` (`resolveTranscript`, `getCurrentTools`, `resolveTranscriptTools` ...), `estimate.ts` (`estimateContextTokens`) and `simple-options.ts` (`resolveSamplingParams`, thinking budgets) are in `superchat-bridge-api-openai-completions.el` under the `superchat-bridge-oc--` prefix; move them when those files have owners.
- openai-completions: constrained sampling (`constrained-sampling.ts`: grammar tools, JSON-schema strict) is not ported; a tool with `constrained-sampling` set ends the stream with an `error` event. Identity headers, Copilot headers, the `fetch` option and the SDK's own default headers are left out.
- openai-completions JSON: request body = alist with symbol keys in source order, vectors for arrays, `t`/`:false`/`:null`, nil is `{}`, an absent key is `undefined`; chunks parse to hash tables with string keys, `:null`, `:false`. `superchat-bridge-oc--json` also takes caller data (tool `parameters`, `arguments`) as hash table, alist, plist, or a list that is no object (array).
- openai-completions timeout: `:timeout-ms` is the time until the response headers (as the SDK's), kept by a timer through `superchat-bridge-retry-run-at-time-function`, not by curl's `--max-time` (which would cut a long stream).
- defect, `superchat-bridge-event-stream-to-list` (event-stream): called on a stream that has not ended and has nothing queued it leaves a waiting continuation, which then swallows the next event pushed (a later `to-list` misses it). Call it only after the producer finished.
- defect, `superchat-bridge--now-ms` is defined twice (models.el rounds, transform-messages.el floors); the last file loaded wins. The NOTES line about `event-stream--time` comparing ms with seconds looks stale: the code now multiplies `started-at` by 1000.
- defect, `superchat-bridge-retry-provider-request` (provider-retry): `:max-retries nil` (a key passed explicitly as nil) breaks the `(<= retries-remaining 0)` test; callers must leave the key out. It also starts the first request even when the signal is already aborted, as the source does (the SDK fails at once there); `superchat-bridge-api-openai-completions` checks the signal before it starts curl.
- catalog (model-catalog): JSON `false` and `{}` both read as nil inside `compat` and the sampling params, so `openRouterRouting: {}` and `false` cannot be told apart; the completions port reads a present nil there as `{}` for routing and as false for sampling params and chat template values.
- anthropic-messages: the file-private copies of `transcript.ts`, `estimate.ts`, `simple-options.ts`, the JSON-schema half of `constrained-sampling.ts` and `appendAssistantMessageDiagnostic` (prefix `superchat-bridge-am--`) duplicate the `superchat-bridge-oc--` ones; move both when those files have owners. A tool's `constrained-sampling` is read as a plist `(:type "json_schema" :strict "prefer"|"require")`; diagnostics are plists.
